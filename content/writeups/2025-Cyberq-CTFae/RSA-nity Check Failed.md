## Challenge Introduction

The **RSA cryptosystem**, introduced in 1977 by Rivest, Shamir, and Adleman, is one of the most widely known public-key encryption schemes and remains a foundational tool in modern cryptography. Its security is based on the computational difficulty of **factoring large composite integers**, specifically products of two large prime numbers. RSA enables both **secure encryption** and **digital signatures**, allowing two parties to exchange confidential messages without sharing a secret key beforehand.

classic sloppy-RNG RSA. The usual and simplest exploit is that the two moduli share a nontrivial factor (the key-generation randomness reused a prime). If that’s true you can factor both moduli by computing `g = gcd(n1, n2)`, then recover the private exponent `d1` for `publickey_1.pem`. Below I explain the math, give a ready-to-run Python script (robust: downloads the PEMs, parses them, tries `gcd`, computes `d1`, prints the SHA-256 of `d1` in the exact format the challenge wants), and show how to verify with the challenge HTTP endpoints.

## Quick math reminder (one-line)

If `n1 = p*q1` and `n2 = p*q2` share prime `p` then `p = gcd(n1, n2)`. Then `phi(n1) = (p-1)*(q1-1)` and `d1 = e1^{-1} mod phi(n1)`.

## Ready-to-run Python script

Save below as `solve_rsa_sharedprime.py`. It:

- downloads `/get-public-key1` and `/get-public-key2` from the challenge host you provide,
    
- extracts `(n, e)` from each PEM,
    
- computes `g = gcd(n1, n2)`,
    
- if `g > 1` factors `n1`, computes `d1`, computes SHA-256 of `d1` as a big-endian integer (the challenge asks to hash the big-endian byte representation), and prints the hash (hex).
    
- includes fallbacks for parsing using either `cryptography` or `pycryptodome`.

```python
#!/usr/bin/env python3
"""
solve_rsa_sharedprime.py

Usage:
  python3 solve_rsa_sharedprime.py http://<CHALLENGE_HOST>

Example:
  python3 solve_rsa_sharedprime.py http://10.0.0.5:8000
"""
import sys
import hashlib
import requests
import math

def fetch_pem(base_url, path):
    url = base_url.rstrip('/') + path
    r = requests.get(url)
    r.raise_for_status()
    return r.content

def parse_pem_get_ne(pem_bytes):
    # Try cryptography first
    try:
        from cryptography.hazmat.primitives import serialization
        from cryptography.hazmat.backends import default_backend
        key = serialization.load_pem_public_key(pem_bytes, backend=default_backend())
        nums = key.public_numbers()
        return nums.n, nums.e
    except Exception:
        pass
    # Fallback to pycryptodome
    try:
        from Crypto.PublicKey import RSA
        key = RSA.import_key(pem_bytes)
        return key.n, key.e
    except Exception as exc:
        raise RuntimeError("Could not parse PEM with cryptography or pycryptodome") from exc

def sha256_of_int_be(n: int) -> str:
    n_bytes = n.to_bytes((n.bit_length() + 7) // 8 or 1, 'big')  # make sure not zero-length
    return hashlib.sha256(n_bytes).hexdigest()

def inv_mod(a, m):
    # Python 3.8+ supports pow(a, -1, m)
    try:
        return pow(a, -1, m)
    except TypeError:
        # fallback extended Euclid
        def egcd(a,b):
            if b==0:
                return (1,0,a)
            x,y,g = egcd(b, a%b)
            return (y, x - (a//b)*y, g)
        x,y,g = egcd(a,m)
        if g != 1:
            raise ValueError("No inverse")
        return x % m

def main():
    if len(sys.argv) != 2:
        print("Usage: python3 solve_rsa_sharedprime.py http://<CHALLENGE_HOST>")
        sys.exit(1)
    base = sys.argv[1].rstrip('/')

    print("[*] Downloading publickey_1.pem ...")
    pem1 = fetch_pem(base, "/get-public-key1")
    print("[*] Downloading publickey_2.pem ...")
    pem2 = fetch_pem(base, "/get-public-key2")

    print("[*] Parsing PEMs ...")
    n1, e1 = parse_pem_get_ne(pem1)
    n2, e2 = parse_pem_get_ne(pem2)

    print(f"[+] n1 bitlen: {n1.bit_length()}, e1: {e1}")
    print(f"[+] n2 bitlen: {n2.bit_length()}, e2: {e2}")

    print("[*] Computing gcd(n1, n2) ...")
    g = math.gcd(n1, n2)
    if g == 1:
        print("[-] gcd == 1 -> no obvious shared prime. Try other attacks (Wiener, close primes, low entropy).")
        sys.exit(2)
    print(f"[+] Found common factor p = gcd = {g}")
    p = g
    if n1 % p != 0:
        print("[-] unexpected: p not divisor of n1")
        sys.exit(3)
    q1 = n1 // p
    if p == 1 or q1 == 1:
        print("[-] trivial factor found, aborting")
        sys.exit(4)
    print(f"[+] n1 factors: p (bits {p.bit_length()}) and q1 (bits {q1.bit_length()})")

    phi1 = (p - 1) * (q1 - 1)
    try:
        d1 = inv_mod(e1, phi1)
    except Exception as exc:
        print("[-] modular inverse failure:", exc)
        sys.exit(5)

    print("[+] Computed d1.")
    digest_hex = sha256_of_int_be(d1)
    print("[*] SHA-256 of the big-endian byte representation of d1 (hex):")
    print(digest_hex)
    print()
    print("[*] If you want to verify with the challenge server run:")
    print(f"  curl {base}/verify-private-key/{digest_hex}")

if __name__ == "__main__":
    main()
```


### Notes about the script

- Requires `requests` and **either** `cryptography` or `pycryptodome` installed. Install with:
    
    - `pip install requests cryptography`
        
    - or `pip install requests pycryptodome`
        
- The script exits with `gcd == 1` if there’s no shared prime. If that happens, the common-prime attack didn’t apply and you must try other attacks (see below).
