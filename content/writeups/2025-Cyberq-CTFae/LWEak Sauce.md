# LWEak Sauce

## Introduction to the Regev Encryption Scheme

The **Regev encryption scheme** is a public-key encryption system based on the **Learning With Errors (LWE)** problem, which is considered hard to solve even for quantum computers.

**The LWE problem says:** > Given a matrix A and a vector b = A . s + e mod q, where s is secret and e is small noise, it is hard to recover s.

Regev encryption served as a starting point for developing some of the most advanced public encryption schemes in Post-quantum Cryptography such as [ML-KEM](https://csrc.nist.gov/pubs/fips/203/final).

---

### Scheme Overview

#### Parameters

- n — dimension of the secret vector

- m — number of LWE samples in the public key

- q — large modulus

- x — error distribution (e.g., discrete Gaussian)

---

#### Key Generation

1. Sample a random vector `s \in \mathbb{Z}_q^n` - uniformly at random
- Sample a random matrix `A \in \mathbb{Z}_q^{m \times n}` uniformly at random
- Sample noise vector of length m from the discrete gaussian distribution `e \leftarrow \chi^m` 
- Compute the vector b= A . s + e (mod q)
- Output: **Public key**: (A, b) , **Private key**: s

---

#### Encryption of a bit `\mu \in \{0,1\}`

- Choose a random binary vector `x \in \{0,1\}^m`
- Compute: `x \in \{0,1\}^m` and `\bar{b} = x^T b + \mu \cdot \text{floor}(q/2) \mod q`
- Output the ciphertext: `c = (\bar{a}, \bar{b})`

Iterate the process to encrypt a bitstring.

---

#### Decryption

1. Compute `v = \bar{b} - \bar{a} \cdot s \pmod{q}:`

If v is closer to 0 than to q/2, output 0; otherwise output 1.

Iterate the process to decrypt a bitstring.

---

## Challenge

The challenge file `ciphertext.pyobj` contains the ciphertext of a message via Regev encryption, which was generated by employing the following implementation of Regev encryption scheme.

```
import random
from math import floor
import numpy as np

def discrete_gaussian_sampler(sigma):
    return int(round(random.gauss(0, sigma)))

def generate_key(n, m, q, sigma):
    a = [np.array([random.randint(0, q - 1) for _ in range(n)], 
                  dtype=np.int64) for _ in range(m)]
    s = np.array([random.randint(0, q - 1) for _ in range(n)], 
                 dtype=np.int64).reshape((n, 1))
    e = [discrete_gaussian_sampler(sigma) for _ in range(m)]
    b = [int(((a[j].dot(s) + e[j]) % q).item()) for j in range(m)]
    public_key = (a, b)
    private_key = s
    return public_key, private_key


def encrypt(public_key, message, m, q):
    A, b = public_key
    random.seed("secret_seed")
    k = random.randint(1, m)
    S = random.sample(range(m), k)
    a_bar = sum([A[i] for i in S]) % q
    c = 0 if message == 0 else 1
    b_bar = (sum([b[i] for i in S]) + c * floor(q / 2)) % q
    return a_bar, b_bar

def decrypt(private_key, ciphertext, q):
    s = private_key
    a, b = ciphertext
    # a is 1D array, s is column vector
    C = int(((b - (a.dot(s) % q)) % q).item())
    if min(C, abs(q - C)) < min(abs(floor(q / 2) - C),
                                abs(C - floor(q / 2))):
        return 0
    else:
        return 1
```

solution script:

```
#!/usr/bin/env python3
"""
solve_regev_chal.py

Usage:
    python solve_regev_chal.py --url http://<CHALLENGE_URL>

This script:
- GETs /get-encrypted-message
- Parses the returned Python-list literal containing ciphertext tuples
- Recovers the 256-bit message by clustering b_bar values (the encryption reseeds
  random to the same seed for each bit, so the subset S is identical for all bits).
- Converts bits -> 64-char hex and calls GET /verify-message/<hex>
- Tries both cluster->bit labelings (in case the chosen reference corresponds to 1).
"""

import argparse
import ast
import sys

import numpy as np
import requests

Q = 16823  # modulus from the challenge
MSG_BITS = 256  # expected message bit length

def load_ciphertext_from_text(text):
    """
    Parse the ciphertext returned by the server (a Python literal).
    Returns list of tuples (a_bar_numpy_array, b_bar_int)
    """
    data = ast.literal_eval(text)
    restored = [(np.array(a_bar, dtype=int), int(b_bar)) for (a_bar, b_bar) in data]
    return restored

def signed_mod_diff(x, y, q=Q):
    """Return difference (x - y) modulo q mapped to range (-q/2, q/2]."""
    d = (x - y) % q
    if d > q // 2:
        d -= q
    return d

def bin_list_to_hex(bin_list):
    if len(bin_list) % 4 != 0:
        raise ValueError("Length of bin_list must be a multiple of 4")
    hex_str = ''
    for i in range(0, len(bin_list), 4):
        nibble = bin_list[i:i+4]
        value = int(''.join(str(b) for b in nibble), 2)
        hex_str += format(value, 'x')
    return hex_str

def decode_bits_from_bbars(bbars, q=Q):
    """
    Attempt to decode bits from b_bar list using a simple clustering relative to bbars[0].
    Returns a tuple (bits_try1, bits_try2) where try2 is inverted labeling of try1.
    """
    if len(bbars) != MSG_BITS:
        print(f"[!] Warning: expected {MSG_BITS} ciphertexts but got {len(bbars)}")

    b0 = bbars[0]
    diffs = [signed_mod_diff(b, b0, q=q) for b in bbars]
    # threshold halfway between 0 and q/2 -> use q/4 as decision boundary
    threshold = q / 4.0
    bits_ref = [0 if abs(d) < threshold else 1 for d in diffs]
    # two possible labelings (since we don't know whether reference corresponds to 0 or 1)
    bits_try1 = bits_ref
    bits_try2 = [1 - b for b in bits_ref]
    return bits_try1, bits_try2

def try_verify(base_url, hex_msg):
    verify_url = base_url.rstrip('/') + '/verify-message/' + hex_msg
    print(f"[+] Trying verification: {verify_url}")
    try:
        r = requests.get(verify_url, timeout=15)
        print(f"[+] HTTP {r.status_code}, response:")
        print(r.text)
        return r
    except Exception as e:
        print(f"[!] Request to verify failed: {e}")
        return None

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument('--url', required=True, help='Base challenge URL, e.g. http://host:port')
    args = ap.parse_args()
    base_url = args.url.rstrip('/')

    get_url = base_url + '/get-encrypted-message'
    print(f"[+] Downloading ciphertext from {get_url} ...")
    try:
        resp = requests.get(get_url, timeout=15)
        resp.raise_for_status()
    except Exception as e:
        print(f"[!] Failed to download ciphertext: {e}")
        sys.exit(1)

    # parse
    try:
        restored = load_ciphertext_from_text(resp.text)
    except Exception as e:
        print(f"[!] Failed to parse ciphertext response: {e}")
        sys.exit(1)

    # show a bit of info
    print(f"[+] Loaded {len(restored)} ciphertext tuples.")
    a_bars = [tuple(x[0].tolist()) for x in restored]
    b_bars = [x[1] for x in restored]

    # quick check: are all a_bar identical? (we expect same S => same a_bar)
    unique_a = {tuple(x[0].tolist()) for x in restored}
    print(f"[+] Unique a_bar count: {len(unique_a)} (expect 1 if S identical across encryptions).")

    # decode bits two ways and attempt verification
    bits1, bits2 = decode_bits_from_bbars(b_bars, q=Q)

    for idx, bits in enumerate((bits1, bits2), start=1):
        try:
            hex_msg = bin_list_to_hex(bits)
        except Exception as e:
            print(f"[!] Failed to convert bits->hex for try {idx}: {e}")
            continue

        if len(hex_msg) != 64:
            print(f"[!] Warning: produced hex length {len(hex_msg)} (expected 64). continuing anyway.")

        print(f"[+] Candidate hex (try {idx}): {hex_msg}")
        r = try_verify(base_url, hex_msg)
        # If the verify endpoint returns something that clearly indicates success, stop.
        if r is not None and (r.status_code == 200 and ("OK" in r.text or "success" in r.text.lower() or "correct" in r.text.lower())):
            print(f"[+] Verification appears successful for candidate {idx}.")
            return

    print("[!] Tried both labelings; if neither succeeded the server response may require a different format or additional steps.")
    print("[+] Debug info (first 10 b_bar values):")
    for i, b in enumerate(b_bars[:10]):
        print(f"  idx {i}: b_bar={b}, diff_from_b0={signed_mod_diff(b, b_bars[0], q=Q)}")

    print("[+] Script finished. If verify didn't accept either mapping, try inspecting the server response or adjust the threshold.")

if __name__ == "__main__":
    main()
```
